# StreamFlix Content Analytics

A complete data analytics project based on a fictional streaming platform, StreamFlix.

## Project Overview

This project analyzes subscriber behavior, content performance, viewing patterns, ratings, reviews, and content investment using Python, MySQL, and Power BI.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Power BI
- Excel

## Project Workflow

1. Data loading and cleaning using Python
2. Exploratory Data Analysis (EDA)
3. SQL-based data analysis
4. Interactive Power BI dashboard
5. Management insights and recommendations

## Dashboard Pages

- Executive Overview
- Content Performance
- Subscriber Insights
- Experience
- Catalogue & Investment
- Management Report

## Key Analysis Areas

- Subscriber and churn analysis
- Monthly watch-hour trends
- Content performance by genre
- Top-performing titles
- Ratings and review sentiment
- Device usage
- Content investment efficiency
- Upcoming licence expiries

## Dataset

The project uses six main datasets:

- Subscribers
- Titles
- Watch History
- Ratings
- Reviews
- Watchlist

A sample version of the large Watch History dataset is included in the repository for GitHub compatibility.
